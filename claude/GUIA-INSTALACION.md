# Instalar en Claude / Anthropic

Son cinco habilidades educativas del laboratorio. Las mismas tareas que en la versión OpenAI. No son skills oficiales de Anthropic ni herramientas clínicas validadas.

1. Escanea el QR de Claude y descarga el ZIP de UNA skill. Si descargas el pack de cinco, descomprímelo: dentro encontrarás cinco ZIP individuales.
2. Revisa su contenido antes de instalar. Cada archivo individual contiene una carpeta con SKILL.md y EJEMPLO.md. No contiene programas ejecutables ni conectores.
3. En tu cuenta de Claude, abre el apartado Skills. Busca la opción de añadir o crear una skill (en la ayuda oficial: “+”, “+ Create skill”) y selecciona la subida de un ZIP. Los nombres y la ubicación pueden variar según versión, plan y permisos del administrador.
4. Sube el ZIP individual, no el pack completo. Confirma o activa la skill si la interfaz lo solicita.
5. Abre un chat nuevo. Pide explícitamente: “Usa lab-ordenes para revisar esta orden ficticia” y aporta los datos del ejemplo. Comprueba que Claude reconoce la skill antes de usarla en tu trabajo.
6. Repite el proceso con las demás. Si tu cuenta no ofrece Skills, utiliza la alternativa de instrucciones de abajo; no la llames instalación nativa.

## Alternativa sin instalación nativa
En la página de cada skill, descarga “Instrucciones para copiar”. Pega ese texto en un chat nuevo y añade tus datos ficticios. Es un uso como prompt reutilizable, no una skill instalada. También puedes guardarlo como instrucciones en un proyecto propio si tu cuenta permite esa función.

## Comprobación de instalación
La skill debe aparecer en tu lista y responder a una petición explícita. Prueba primero EJEMPLO.md: compara la respuesta con sus criterios esperados, no con supuestos resultados ya ejecutados. La disponibilidad de herramientas, lectura de archivos y cálculos depende de la cuenta. Si falta una capacidad, la skill debe decirlo.

## Seguridad
Cada asistente utiliza su propia cuenta. No subas identificadores de pacientes, documentos confidenciales ni datos sanitarios sin evaluar permisos, privacidad y contrato del proveedor. Estos ejemplos son sintéticos. No hay envíos, aprobaciones ni decisiones clínicas automáticas.
